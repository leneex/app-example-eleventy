# Eleventy

Пример статического сайта на [Eleventy](https://www.11ty.dev/), который можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Статический сайт — сборка Railpack |
| Одностраничное приложение (SPA) | выключено |
| Путь до директории проекта | `/` |
| Директория сборки | `/_site` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Путь проверки состояния | `/` |

Порт указывать не нужно: статический сайт отдаётся на порту 80. Railpack ставит
зависимости и запускает `npm run build`, Eleventy кладёт готовые страницы в `_site`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
npm install

# запуск в режиме разработки
npm run dev

# сборка для продакшн
npm run build
```

Нужен Node.js 22 или новее.

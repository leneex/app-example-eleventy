# Eleventy

Example [Eleventy](https://www.11ty.dev/) static site. Eleventy (11ty) is a simple static site generator that turns templates and Markdown into HTML.

## Deploy settings

| Field | Value |
| --- | --- |
| Build | Static site — Railpack build |
| Single-page application (SPA) | off |
| Project directory | `/` |
| Output directory | `/_site` |
| Install command | leave empty |
| Build command | leave empty |
| Health check path | `/` |

## <a name="dev"></a>Run locally

```bash
# install dependencies
npm install

# run in development mode
npm run dev

# build for production
npm run build
```

Requires Node.js 22 or later.
